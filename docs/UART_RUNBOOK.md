# UBOX10 UART 被动监听手册（免焊优先）

## 适用范围与风险等级

本手册只用于收集启动日志，不用于登录、打断 U-Boot、发送命令或刷写。

- **被动接收接线**：低风险；只接地和板端 TX，适配器不会向板子供电或发送电平。
- **错误接线/不明针脚**：中风险；可能短路、反灌电源或向错误引脚施加电压。
- **主动 TX、VCC、短接启动脚**：高风险；当前阶段禁止。

J21 的针脚顺序和电平**尚未在本项目中验证**。不得仅凭“J21: GND TX RX”的文字假设从左到右顺序；应以 PCB 丝印、清晰照片或连续性测量为准。

## 无焊接所需物品

1. 具备 **3.3V TTL 逻辑**的 USB-UART 适配器：CP2102 或 FT232 优先；CH340 仅在明确支持 3.3V I/O 时使用。
2. 两根母对母杜邦线；若 J21 未焊排针，准备 pogo pin、夹具或由有经验者焊接排针。
3. 终端软件（PuTTY、Tera Term 或等效工具），支持原始日志落盘。

绝不可使用传统 USB-to-RS-232 适配器（其信号可能为正负十余伏），不可使用 5V TTL，不可接适配器的 VCC 引脚。没有万用表时，仍可使用高阻的适配器 RX 做被动接收；不要因此猜测或连接电源/主机 TX。

如果 J21 是未焊的焊盘：不要用裸线、鳄鱼夹或探针在相邻焊盘间悬挂接触。优先使用稳定的 pogo pin 夹具；若无法稳定固定，停止并记录为硬件阻塞，而不是冒险试接。

## 首次接线：只接收

先给 UBOX10 **断电**，再按下图接线：

```text
UBOX10 J21 GND  ───────── USB-UART GND
UBOX10 J21 TX   ───────── USB-UART RX

UBOX10 J21 RX   ────────  不连接
UBOX10 3.3V/VCC ────────  不连接
USB-UART TX     ────────  不连接
USB-UART VCC    ────────  不连接
```

这条接线的恢复方式就是拔掉两根线。其目的只是让适配器观察板端发送的数据；它不能控制设备，也不应改变 USB/启动状态。

## 捕获步骤

1. 接入 USB-UART 到电脑，确认 Windows 识别到 COM 口；不要接任何 VCC。
2. 打开终端并选择该 COM 口，初始设置：**115200 baud、8 data bits、no parity、1 stop bit、no flow control**。
3. 启用原始会话日志，建议文件名为：`logs/device/<run-id>/uart-current-115200.txt`。
4. 在终端已打开并开始记录后，给 UBOX10 上电；全程不要按键、不要向终端输入字符。
5. 捕获至少 30 秒，或直到 Recovery 界面稳定后再等待 10 秒；保存原始日志、接线照片、设备屏幕照片和采集时间。
6. 计算日志 SHA-256，并在同目录写入一个简短的 `README.md`，说明适配器型号、COM 号、波特率、线材和设备状态。

若完全无输出，先检查 GND 和 TX/RX 是否接反、端口是否正确、J21 针脚是否已实际接触。可在**另存为新日志**的前提下依次尝试 `1500000`、`921600` 与 `115200`；不要通过连接 TX、VCC 或短接其他引脚“增加成功率”。

## 结果判读

| 现象 | 可能含义 | 安全下一步 |
|---|---|---|
| 可读的 BootROM/U-Boot 文本 | 成功获得早期启动链证据 | 保存完整日志；先分析而非发送命令。 |
| 乱码但持续输出 | 波特率、数据格式或电平不匹配 | 换波特率并单独保存日志；保持被动接线。 |
| 完全无输出 | TX/RX、GND、针脚、端口或启动路径未确认 | 复核丝印/接触；不改接 VCC/TX。 |
| 上电异常、异味、发热、显示异常 | 可能存在接线问题 | 立即断电、拔线；拍照记录，停止实验。 |

## 后续日志策略

优先采集**当前设备状态**的日志，因为它无需刷写。只有在官方回退过程已被单独评审且用户决定恢复官方固件后，才采集官方基线日志以做差分；恢复官方固件本身是严重风险操作，不属于本手册授权范围。
